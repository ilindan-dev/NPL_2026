# 2.3 Scala - Top K Frequent Elements (LeetCode 347), итеративное решение

Дан массив чисел и `k`. Нужно вернуть `k` самых часто встречающихся элементов.
Пример: `[1,1,1,2,2,3]`, `k = 2` → `[1,2]`.

## Запуск

```bash
./run.sh 2_algorithms/task_3_scala                     # примеры из LeetCode + случайный
./run.sh 2_algorithms/task_3_scala 2 4 4 4 7 7 9 9 9 9  # свои: k, затем числа
```

## Как устроено

**Основное решение** - цепочка методов коллекций, без изменяемых переменных:

```scala
nums
  .groupMapReduce(identity)(_ => 1)(_ + _)  // Map(число -> частота)
  .toSeq
  .sortBy((num, count) => (-count, num))    // по убыванию частоты
  .take(k)
  .map(_._1)
```

`groupMapReduce` за один проход группирует элементы (по самому числу), заменяет каждый
на 1 и складывает единицы. Получается таблица частот. Дальше сортировка и первые `k`.
Сложность O(n log n).

**Дополнительно - bucket sort за O(n)** (follow-up в условии LeetCode). Частота не может
быть больше `n`, поэтому числа раскладываются по «корзинам» с индексом-частотой. Затем
корзины обходятся с конца, пока не наберётся `k` чисел. Программа проверяет, что оба
способа дали одно и то же.

Для наглядности в выводе показаны промежуточные шаги: частоты → сортировка → первые k.
