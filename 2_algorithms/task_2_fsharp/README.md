# 2.2 F# — Lowest Common Ancestor of a Binary Tree (LeetCode 236), рекурсия

Дано бинарное дерево и два его узла `p` и `q`. Нужно найти их наименьшего общего предка,
то есть самый глубокий узел, у которого оба являются потомками (узел считается потомком
самого себя).

## Запуск

```bash
./run.sh 2_algorithms/task_2_fsharp          # примеры из условия LeetCode
./run.sh 2_algorithms/task_2_fsharp 7 0      # свои p и q
```

Первый запуск .NET в контейнере занимает несколько секунд, это нормально.

## Как устроено

**Дерево — алгебраический тип (discriminated union):**
```fsharp
type Tree =
    | Empty
    | Node of value: int * left: Tree * right: Tree
```
Дерево либо пустое, либо это узел со значением и двумя поддеревьями. `null` не используется.

**Алгоритм `lca` — один рекурсивный проход через сопоставление с образцом (`match`):**

1. Пустое дерево → `None`.
2. Текущий узел равен `p` или `q` → возвращаем его. Глубже искать не нужно: если второй
   узел ниже, ответ всё равно этот.
3. Иначе ищем в левом и правом поддереве:
   - нашли в **обоих** → текущий узел и есть общий предок;
   - нашли в одном → передаём найденное наверх;
   - нигде → `None`.

Сложность O(n): каждый узел посещается один раз.

`fromLevelOrder` строит дерево из массива в формате LeetCode (`[3,5,1,6,2,0,8,null,null,7,4]`).
`printTree` рисует дерево «на боку».

## Шпаргалка для видео

1. *«Задача 2.2 на F#: наименьший общий предок в бинарном дереве, LeetCode 236. Рекурсивное решение».*
2. Показать тип `Tree`: *«Дерево задано алгебраическим типом: либо Empty, либо Node со значением и двумя поддеревьями. Компилятор проверяет, что в match разобраны все случаи».*
3. Показать `lca`: *«Три случая. Пусто: ничего не нашли. Узел равен p или q: возвращаем его. Иначе рекурсивно ищем слева и справа. Если нашлось в обоих поддеревьях, текущий узел и есть ответ, иначе поднимаем то, что нашлось».*
4. Запуск без аргументов: *«Вот дерево из примера LeetCode. Для 5 и 1 ответ 3, корень. Для 5 и 4 ответ 5: узел может быть предком самого себя».*
5. Запуск с `7 0`: *«Можно передать свои узлы».*

## Возможные вопросы

- **Почему `Option`, а не `null`?** Отсутствие результата явно видно в типе, и компилятор заставляет его обработать.
- **Что, если узла нет в дереве?** LeetCode гарантирует, что оба есть. Здесь перед поиском стоит проверка `contains`.
