# 2.4 OCaml - Container With Most Water (LeetCode 11), итеративное решение

Дан массив высот вертикальных линий. Нужно выбрать две линии, которые вместе с осью X
образуют контейнер с наибольшей площадью воды. Пример: `[1,8,6,2,5,4,8,3,7]` → `49`
(линии 1 и 8: ширина 7, высота min(8,7) = 7).

## Запуск

```bash
./run.sh 2_algorithms/task_4_ocaml                 # пример из LeetCode
./run.sh 2_algorithms/task_4_ocaml 4 3 2 1 4       # свои высоты
```

## Как устроено

**Два указателя.** `l` стоит в начале, `r` в конце. На каждом шаге:

1. площадь = `(r - l) * min(h[l], h[r])`, запоминаем максимум;
2. сдвигаем к центру **ту стенку, что ниже**.

Почему именно меньшую? Высота воды ограничена меньшей стенкой. Если сдвинуть большую,
ширина уменьшится, а высота не вырастет, то есть площадь точно не станет больше.
Сдвигая меньшую, мы хотя бы можем найти стенку повыше. Так за **один проход O(n)**
перебираются все перспективные пары, вместо O(n²) пар при полном переборе.

В коде это цикл `while` со ссылками `ref` - обычный итеративный стиль, который OCaml
тоже поддерживает.

Программа выводит каждый шаг указателей, рисует ответ (`#` - линии, `~` - вода)
и проверяет алгоритм на 1000 случайных массивах против полного перебора.
