# 2.1 Prolog — Generate Parentheses (LeetCode 22), рекурсия

По числу `n` нужно выдать все правильные скобочные последовательности из `n` пар.
Например, для `n = 3`: `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.

## Запуск

```bash
./run.sh 2_algorithms/task_1_prolog        # n = 3
./run.sh 2_algorithms/task_1_prolog 4      # n = 4 (14 вариантов)
```

## Как устроено

Вся логика в трёх правилах `parens(Open, Close, Chars)`. `Open` — сколько `(` ещё
можно поставить, `Close` — сколько `)` ещё нужно поставить:

| Правило | Когда срабатывает | Что делает |
|---|---|---|
| `parens(0, 0, [])` | скобок не осталось | последовательность готова |
| `parens(Open, Close, ['('\|Rest])` | `Open > 0` | ставим `(`, рекурсия с `Open-1` |
| `parens(Open, Close, [')'\|Rest])` | `Close > Open` | ставим `)`, рекурсия с `Close-1` |

Условие `Close > Open` означает, что открытых скобок сейчас больше, чем закрытых.
Только тогда можно закрыть, иначе последовательность станет неправильной.

**Backtracking здесь не пишется вручную.** Prolog сам пробует первое подходящее правило,
а когда ветка заканчивается (успехом или неудачей), возвращается и пробует следующее.
`findall` собирает все решения в список.

Для самопроверки программа сравнивает количество ответов с числом Каталана
`C(n) = (2n)! / ((n+1)! · n!)` для `n = 1..8`.

## Шпаргалка для видео

1. *«Задача 2.1 на Prolog: генерация правильных скобочных последовательностей, LeetCode 22. Это рекурсия с перебором с возвратом».*
2. Показать три правила `parens`: *«Решение — это три правила. Базовый случай: скобки кончились. Можно открыть, если открывающие остались. Можно закрыть, если открытых больше, чем закрытых».*
3. *«Цикла перебора здесь нет: Prolog сам перебирает варианты. Когда ветка закончилась, он возвращается назад и пробует следующее правило. Это и есть backtracking».*
4. Показать `generate_all` с `findall`: *«findall собирает все решения в список, как ответ на LeetCode».*
5. Запуск для 3 и 4: *«Для трёх пар 5 последовательностей, для четырёх 14. Это числа Каталана, программа это проверяет до n = 8».*

## Возможные вопросы

- **Почему ответы идут в таком порядке?** Правило с `(` стоит раньше правила с `)`, поэтому Prolog сначала пробует открывать. Получается лексикографический порядок.
- **Сложность?** Пропорциональна числу ответов `C(n) ≈ 4ⁿ / (n^1.5)`. Тупиковых веток нет: условия отсекают неправильные префиксы сразу.
