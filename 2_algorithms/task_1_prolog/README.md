# 2.1 Prolog - Generate Parentheses (LeetCode 22), рекурсия

По числу `n` нужно выдать все правильные скобочные последовательности из `n` пар.
Например, для `n = 3`: `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.

## Запуск

```bash
./run.sh 2_algorithms/task_1_prolog        # n = 3
./run.sh 2_algorithms/task_1_prolog 4      # n = 4 (14 вариантов)
```

## Как устроено

Вся логика в трёх правилах `parens(Open, Close, Chars)`. `Open` - сколько `(` ещё
можно поставить, `Close` - сколько `)` ещё нужно поставить:

| Правило | Когда срабатывает | Что делает |
|---|---|---|
| `parens(0, 0, [])` | скобок не осталось | последовательность готова |
| `parens(Open, Close, ['('\|Rest])` | `Open > 0` | ставим `(`, рекурсия с `Open-1` |
| `parens(Open, Close, [')'\|Rest])` | `Close > Open` | ставим `)`, рекурсия с `Close-1` |

Условие `Close > Open` означает, что открытых скобок сейчас больше, чем закрытых.
Только тогда можно закрыть, иначе последовательность станет неправильной.

**Backtracking здесь не пишется вручную.** Prolog сам пробует первое подходящее правило,
а когда ветка заканчивается (успехом или неудачей), возвращается и пробует следующее.
`findall` собирает все решения в список.

Для самопроверки программа сравнивает количество ответов с числом Каталана
`C(n) = (2n)! / ((n+1)! · n!)` для `n = 1..8`.
