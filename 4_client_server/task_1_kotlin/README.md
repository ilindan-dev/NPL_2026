# 4.1 Kotlin - синхронизация общего списка задач (To-Do) в реальном времени

Сервер хранит список задач в памяти. Клиенты подключаются по TCP и отправляют команды
`ADD <текст>`, `REMOVE <id>`, `LIST`, `QUIT`. **При любом изменении сервер рассылает
обновлённый список всем подключённым клиентам**, поэтому у всех на экране одно и то же.
Используется только стандартная библиотека: `java.net.ServerSocket`/`Socket` и потоки.

## Запуск (порт 5001)

Нужно три терминала, все открываются в корне репозитория:

```bash
# терминал 1 - сервер
./run.sh 4_client_server/task_1_kotlin server

# терминал 2 и 3 - клиенты
./run.sh 4_client_server/task_1_kotlin client
```

В клиенте вводим, например:
```
ADD Сдать лабу по NPL
ADD Купить молоко
REMOVE 2
LIST
QUIT
```

Подключиться можно и без нашего клиента: `nc localhost 5001` (или `telnet localhost 5001`).

## Как устроено

**Сервер (`TodoServer`)**
- `ServerSocket.accept()` в цикле. На каждого клиента отдельный поток (`thread { handle(c) }`).
- `tasks` и `nextId` общие для всех потоков, поэтому любое чтение и изменение идёт внутри
  `synchronized(lock)`.
- `clients` - `CopyOnWriteArrayList`. Его можно безопасно обходить при рассылке, пока
  другой поток добавляет или удаляет клиента.
- `broadcast(event)` - строка события (`клиент#1 добавил #3`) плюс снимок списка, всем клиентам.
- `Client.send` синхронизирован по потоку вывода. Если два потока одновременно шлют
  сообщения одному клиенту, строки не перемешаются.
- Отключение клиента (QUIT, обрыв, Ctrl+C) обрабатывается в `finally`: удаляем его из
  списка и закрываем сокет.

**Клиент (`runClient`)** - два потока:
- фоновый поток читает сокет и печатает всё, что прислал сервер (в том числе изменения
  от **других** клиентов);
- главный поток читает клавиатуру и отправляет строки на сервер.

**Протокол** - текстовый, построчный (`readLine`/`println`), кодировка UTF-8.
