# 5.3 Objective-C - конвертер Markdown → HTML

Программа читает `.md` файл и генерирует HTML-документ с минимальными стилями.

| Markdown | HTML |
|---|---|
| `#` … `######` | `<h1>` … `<h6>` |
| `**жирный**`, `*курсив*`, `` `код` `` | `<b>`, `<i>`, `<code>` |
| `[текст](url)` | `<a href="url">` |
| пустая строка | граница абзаца `<p>` |
| `- пункт`, `1. пункт` | `<ul><li>`, `<ol><li>` |
| `> цитата` | `<blockquote>` |
| блок в тройных кавычках | `<pre><code>` |
| `---` | `<hr>` |

Спецсимволы `& < >` экранируются, поэтому `<b>` внутри кода выводится как текст.

Objective-C вне macOS - это компилятор GCC и **GNUstep Base**, открытая реализация
Foundation (`NSString`, `NSArray`, ...). В Docker-образе ставятся они.

## Запуск

```bash
./run.sh 5_convert/task_3_objc examples/sample.md                       # HTML в консоль
./run.sh 5_convert/task_3_objc examples/sample.md examples/sample.html  # в файл
xdg-open 5_convert/task_3_objc/examples/sample.html                     # открыть в браузере
```

## Как устроено

Класс `MarkdownConverter`, два уровня разбора.

**1. Блоки (`convert:`)** - проход по строкам. Состояние хранится в полях объекта:
- `inCode` - внутри блока кода: строки идут дословно, только с экранированием;
- `paragraph` - накопленные строки текущего абзаца. Абзац закрывается пустой строкой
  или началом другого блока (`flushParagraph`). Так соседние строки склеиваются в один `<p>`;
- `listTag` - открытый список (`ul`/`ol`). Пункты подряд попадают в один список, а при
  смене типа или пустой строке он закрывается.

Для каждой строки по очереди проверяется: заголовок (`headerLevel` считает `#`),
`---`, пункт списка, цитата, иначе обычный текст.

**2. Строчная разметка (`inlineMarkup:`)** - посимвольный проход по уже экранированной
строке с флагами `bold`/`italic`/`code`:
- `**` переключает `<b>`, `*` - `<i>`, `` ` `` - `<code>` (внутри кода остальное не трогается);
- маркер открывается, только если **дальше есть парный** (`hasCloser`), поэтому
  `2 * 3` остаётся текстом;
- `[текст](url)` ищется через `rangeOfString:`;
- в конце незакрытые теги закрываются.

Память управляется вручную (`retain`/`release`, `NSAutoreleasePool`), без ARC: так код
собирается и GCC, и clang.
