# 5.1 Elixir — конвертер JSON → XML

Программа читает JSON-файл с объектами и массивами и рекурсивно переводит его в XML-теги
с отступами (pretty-print).

```json
{ "address": { "city": "Москва" }, "tags": ["классика", "роман"], "note": null }
```
```xml
<root>
  <address>
    <city>Москва</city>
  </address>
  <tags>
    <item>классика</item>
    <item>роман</item>
  </tags>
  <note/>
</root>
```

## Запуск

```bash
./run.sh 5_convert/task_1_elixir examples/library.json                     # XML в консоль
./run.sh 5_convert/task_1_elixir examples/library.json examples/library.xml # в файл
./run.sh 5_convert/task_1_elixir examples/broken.json                      # ошибка с позицией
```

## Как устроено

**1. Парсер JSON (`Json`)** написан вручную. Встроенный модуль `JSON` есть только с
Elixir 1.18 и возвращает обычную мапу, а в мапе порядок ключей теряется. Для XML порядок
важен, поэтому объект хранится как список пар `{:object, [{ключ, значение}, ...]}`.

Парсер — набор рекурсивных функций с **сопоставлением с образцом по бинарным строкам**:
```elixir
defp value("{" <> rest), do: object(...)
defp value("[" <> rest), do: array(...)
defp value("true" <> rest), do: {true, rest}
```
Каждая функция откусывает начало строки и возвращает `{значение, остаток}`. Поддержаны
escape-последовательности, включая `\uXXXX` и суррогатные пары (эмодзи). При ошибке
вычисляется **строка и столбец**: позиция = сколько байт уже разобрано.

**2. Генератор XML (`Xml`)** — рекурсия по дереву:
- объект → тег, внутри теги ключей;
- массив → тег, внутри `<item>` на каждый элемент;
- `null`, `{}`, `[]` → пустой тег `<tag/>`;
- строки экранируются (`&` → `&amp;`, `<` → `&lt;`, ...);
- ключи, недопустимые как имена тегов, исправляются: `"first name"` → `first_name`,
  `"2fa"` → `_2fa`.

Результат собирается как **iodata** (вложенные списки строк) и склеивается один раз
в конце. Это идиоматичный и быстрый способ строить большой текст в Elixir.

## Возможные вопросы

- **Почему `item`?** У XML нет массивов. Повторяющиеся элементы — обычный способ их представить.
- **Как отличить строку `"5"` от числа `5` в XML?** В этой версии никак: XML хранит только текст. Если нужно, можно добавить атрибут `type="number"`.
