# 3.1 Perl - CLI-генератор структуры директорий (аналог `tree`)

Скрипт принимает путь к папке, рекурсивно обходит её и рисует дерево вложенности
псевдографикой `├── │ └──`. Папки идут первыми и выделяются цветом. В конце выводится
итог «N папок, M файлов» с правильными русскими окончаниями.

## Запуск

`run.sh` монтирует репозиторий в контейнер, текущая папка = папка задачи.

```bash
./run.sh 3_io/task_1_perl ../..            # дерево всего репозитория
./run.sh 3_io/task_1_perl -s ../..         # с размерами файлов
./run.sh 3_io/task_1_perl -L 1 ../..       # только первый уровень
./run.sh 3_io/task_1_perl -d ../..         # только папки
./run.sh 3_io/task_1_perl -a -L 1 ../..    # со скрытыми (.git, .gitignore)
./run.sh 3_io/task_1_perl -o tree.txt ../..  # ещё и сохранить в файл tree.txt
```

Без Docker: `perl tree.pl [опции] [папка]` (Perl есть почти в любом Linux).

## Как устроено

- **Разбор аргументов** - стандартный модуль `Getopt::Long`.
- **`walk($dir, $prefix, $depth)`** - рекурсивная функция:
  1. `opendir`/`readdir` - список содержимого, без `.` и `..`;
  2. фильтры (скрытые, только папки) и сортировка: папки первыми, затем по алфавиту;
  3. для каждого элемента печатается `префикс + ветка + имя`. Ветка - `└── ` для последнего
     элемента, `├── ` для остальных;
  4. для папки - рекурсивный вызов с удлинённым префиксом: `"│   "`, если у родителя ниже
     ещё есть элементы, или `"    "`, если это был последний. Так вертикальные линии
     тянутся ровно до последнего ребёнка.
- Символьные ссылки показываются как `имя -> цель`, внутрь них обход не заходит
  (защита от зацикливания).
- Имена файлов декодируются как UTF-8, поэтому русские имена выводятся правильно.
- `-o FILE` пишет то же дерево в файл без цветовых escape-кодов.
