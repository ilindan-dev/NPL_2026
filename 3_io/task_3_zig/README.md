# 3.3 Zig - консольный Pomodoro-таймер с логированием сессий

Таймер для работы по технике Pomodoro: 25 минут работы, 5 минут перерыва.
В консоли идёт обратный отсчёт с полосой прогресса, строка обновляется на месте.
Когда время вышло, звучит сигнал (`\a`), а в `stats.txt` **дописывается** строка с датой
и длительностью сессии. В конце печатается сводка по всему файлу: сколько сессий и
сколько времени всего.

Код написан под **Zig 0.13.0** (Zig ещё не 1.0, и API стандартной библиотеки меняется
между версиями, поэтому версия в Dockerfile зафиксирована).

## Запуск

```bash
./run.sh 3_io/task_3_zig                # классика: 25 мин работы, 5 мин перерыв
./run.sh 3_io/task_3_zig 10s 5s 2       # для демонстрации: 2 цикла по 10 секунд
cat 3_io/task_3_zig/stats.txt
```

Длительность: `25m`, `90s`, `1h`, или просто число (минуты).
Время в логе в UTC (в контейнере нет часового пояса).

## Как устроено

- **`parseDuration`** - разбор `"10s"`/`"25m"`/`"1h"` через `switch` по последнему символу
  и `std.fmt.parseInt`. Ошибки разбора - это значения типа ошибки (`!u32`): `try` передаёт
  их выше, `catch` обрабатывает на месте.
- **`countdown`** - цикл: печать `\r  Работа  00:07  [#####-----]`, `std.time.sleep(1 с)`,
  `left -= 1`. Символ `\r` (возврат каретки) переводит курсор в начало строки, поэтому
  следующая печать перерисовывает строку.
- **Сигнал** - символ BEL `\x07`, терминал на него пищит или мигает.
- **`appendStats`** - `createFile(..., .{ .truncate = false })` открывает файл без затирания
  (или создаёт его), `seekFromEnd(0)` переходит в конец, затем запись строки. Дата
  считается из Unix-времени через `std.time.epoch`.
- **`printSummary`** - чтение файла целиком (`readFileAlloc`), разбиение на строки,
  разбор секунд из последнего поля.
- Память: аллокатор `GeneralPurposeAllocator`, всё освобождается через `defer`.
  В Debug-сборке GPA сообщает об утечках.
